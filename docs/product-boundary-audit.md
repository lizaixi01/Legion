# 产品边界离线审计

2026-10-04。当前范围是默认产品装配、聊天、桌面服务及发布树。历史实验和旧审计在独立归档保全；本清单不改变它们的承诺。

- 核实本地 HEAD、暂存区、未提交文件和实际远端；隔离实现，保留原工作区其他工作。
- 先保存并校验源码及将移出的材料，再从当前产品树移除专用模块、配置、脚本、测试、报告和资产。
- 默认 `primary-agent` 只使用通用工具与提示，保留原通用接口和可选宿主能力工厂。
- 检查 `desktop/main.cjs` 的每个动态服务入口及传递依赖，覆盖产品装配与 renderer 的真实资源图。
- 在没有项目专用代码、资产与工具链的隔离目录中，通过实际桌面主进程 IPC 完成聊天、派发、交付检查与历史读取。
- 保留最大化、最小化、策略身份、哈希绑定、恢复、预算、取消、异常与资源排空行为回归。
- 旧记录含附加字段时可读；读取前后文件哈希一致，不从旧证据获得当前权限。
- 配置模块导入不启动工作或写文件；移除失效命令、导出与文档链接。
- 用旧输出污染夹具证明构建会清除历史编译残留，检查实际编译树及发布包，不打包仓库自有测试和实验材料。
- 不调用真实模型、容器验证器或 benchmark；不修改原验证器、指标、状态格式或预算语义，不升级环境。
- 最终差异检查后按代码/验收与文档职责提交；再次核对实际远端，保留更新，正常推送工作分支。

验收结果只能按本轮实际日志填写；未运行的真实模型、系统窗口交互、已安装版本更新、多日可靠性和性能实验均不得记为通过。回滚必须同步撤回实现和依赖其行为的测试断言，并重新清理构建；契约文档可保留。当前范围与限制见[实现状态](implementation-status.md)。

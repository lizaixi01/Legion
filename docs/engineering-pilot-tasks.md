# 代码工程开发试跑任务提案

日期：2026-10-02。状态：三项真实项目需求提案，终局评测器未实现，尚未开始模型试跑；不是 20–30 题正式任务集。baseline 统一为 Legion `de0490586847dd951fd00fe4e460123e741396bd`；不得把当前改进分支作为某一臂的额外上下文。目标实验设计见[协议](three-arm-engineering-protocol.md)。

## P1：贯通宿主领域验收注册

原始需求：普通主会话与持续 Goal 可以使用宿主安装的领域 verifier，覆盖数值聚合之外的交付；模型不能自行注册验证器、上传命令或用 JSON PASS 获得认证。未覆盖要求保持 unverified。恢复原需求与输入绑定，旧 PASS 不认证当前文件。

跨模块范围：`src/primary-runtime.ts` 的组合依赖、`src/primary-delivery.ts` 的 registry、`src/primary-capability.ts` 的宿主能力、`src/contact-verifier.ts` 的原输入冻结，及主会话/Goal 的恢复路径。现状：交付服务已有可注入 registry，但主会话组合未贯通；联系人 verifier 存在于旧入口。

验收清单：默认数值聚合不回归；宿主安装的联系人清洗端到端获得覆盖；错误排序/重复/额外联系人被拒绝；模型选择任意 verifier/伪造 PASS/改变原输入不能通过；重启后旧证据只读参考，新检查绑定原契约与输入；取消/期限和未覆盖状态不被降级为通过。终局检查应使用假模型驱动真实主会话工具路由，不能只测试一个新的纯函数。

## P2：Git Worker 候选与复验

原始需求：对 Git 工程，每个 Worker 使用独立分支/worktree，提交候选身份含 commit 与 tree。验收在固定版本上进行，集成后的 root tree 重新检查。保留非 Git 和历史快照兼容、可恢复状态及证据篡改检测。

跨模块范围：Worker workspace 生命周期、候选捕获/manifest、交付证据、恢复与取消、集成检查。现状：工程已有 Git，Worker 仍主要复制文件/目录并计算 SHA256；该需求不等于把一个路径字段改名。

验收清单：两个 Worker 不覆盖源检出或彼此文件；同名任务/重试不复用已污染 worktree；目录含空格可用；有未提交源修改时遵循冻结输入规则；候选及集成结果绑定正确 commit/tree；检测检出后字节变化、缺失对象/外部输入、恢复身份不一致；清理只处理本运行拥有的资源，不删除用户 worktree；取消/失败保留可审计证据。复验命令在全新检出运行实际冻结检查，不能仅打印 hashes。

## P3：按运行配置并记录 CLI runtime

原始需求：保留默认固定 Codex 版本的可复现性，同时允许宿主对新运行显式选择 runtime；主会话、Worker 与容量探针使用一致选择并记录实际版本/二进制 hash。不能因 PATH 或全局升级悄悄换执行器，不能原地升级冻结实验。

跨模块范围：`src/codex-runtime.ts`、主会话创建、Worker spec、容量/启动预检、工程运行冻结与恢复、安装和配置文档。现状：本地默认固定 0.159.2，旧 Linux benchmark 另有配置，二者不应混为一个统一版本。

验收清单：未配置时兼容默认路径；显式 runtime 在所有调用入口一致；缺失/版本不符/二进制变化有明确预检或恢复阻塞；假 CLI 记录 argv、cwd、权限和身份供独立断言；目录含空格可用；不修改全局配置或其他运行；Command Code 保持独立能力声明。无需调用真实模型或随意升级共享安装。

## 开跑前还缺什么

逐题实现宿主冻结终局评测器并用正例/错误实现验证；准备独立依赖及可分发输入；接通 A/B/C 开关、全角色预算和成本观测；定义 final candidate 选择；核对原始仓库/第三方材料许可并封存任务包。然后才把[空计划](experiment-data/engineering-pilot-plan.json)的 frozen 改为 true，并填写实际输入/评测器/协议哈希。

这些开发题有工程价值，但与当前 backlog 和设计者知识重叠。正式效果必须在新的未调优任务集上测量；不能将它们包装成九次已完成的真实长程实验。

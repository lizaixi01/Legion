# 外部项目与默认产品装配

2026-10-04，实施。

默认产品只需要通用任务、资源、候选、检查、证据和恢复能力。外部项目通过自己的项目说明、文件和命令使用产品，不需要产品内置其指标、环境、提示或专用工具。

默认 `primary-agent` 直接装配通用运行时。保留 `ResearchDeps`、`QualityPolicy`、`PrimaryCapability` 及所有通用接口；移除旧项目专用模块、兼容包装和实验 CLI。桌面只读取与展示通用历史，不触发旧项目的检查；历史记录不改写。构建先清空本工作树输出，产品编译和发布排除仓库自有测试及实验材料。

两个管理循环、预算语义、通用队列、模型代理和资源清理继续保留。本轮不加环境安装器、搜索策略或新领域能力。先在仓库外保存源码、旧审计、冻结实现、报告与原始记录，校验哈希后再移出产品树；不重写 Git 历史。此前决策及承诺保留在原始独立归档中，不改写为本轮承诺。

回滚必须同步撤回实现与依赖该实现的断言，并清理重新构建发布文件；契约要求可继续保留。源码和用户数据分别恢复，不将历史通过记录作为当前验收权限。具体边界见[架构说明](../architecture-boundaries.md)。
